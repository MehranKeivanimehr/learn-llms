## From token to vector

A model can't do math on the text "queen", so it looks each token up in a table and replaces it with a list of numbers: an **embedding**. Real models use thousands of numbers per token; ours uses two, so we can draw them as arrows.

## Similar meanings point the same way

To compare two vectors, models often use **cosine similarity**: how closely do the arrows point in the same direction? 1 means the same direction, 0 a right angle, −1 opposite. Length doesn't matter.

## Directions carry meaning

In trained embeddings, going from "man" to "woman" is roughly the same step as from "king" to "queen". That's why **king − man + woman ≈ queen** works (approximately).
