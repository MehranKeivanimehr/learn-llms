## A real (tiny) language model

This level runs an actual transformer in your browser. It has every piece you've met: embeddings, position signals, one attention block with an MLP and residual connections, and a final layer that scores every possible next character. (To keep it tiny, it skips layer norm.)

It was trained on just two public-domain nursery rhymes, so it has basically memorized them. Real LLMs work the same way, but with billions of parameters, thousands of blocks' worth of computation and trillions of tokens of training text.

## The loop

Generation is the loop from level 1, for real:

1. Turn the text into tokens (here, single characters).
2. Run the model to get a probability for every possible next token.
3. Pick one (greedy or sampled — level 4).
4. Append it and go back to step 1.

The model has a **context window**: it can only see the last 16 characters. Anything earlier is simply gone. Real models have much bigger windows — hundreds of thousands of tokens — but the limit is the same idea.
